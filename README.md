# To-Do List App

## 📌 Project Overview
The To-Do List App is a simple web application built using HTML, CSS, and JavaScript. It helps users organize their daily tasks by adding new tasks, marking tasks as completed, and deleting tasks when they are no longer needed.

## ✨ Features
- Add new tasks to the list.
- Mark tasks as completed.
- Delete tasks individually.
- Simple and user-friendly interface.
- Responsive design for different screen sizes.
- Interactive functionality using JavaScript.

## 🛠️ Technologies Used
- **HTML5** – Creates the structure of the application.
- **CSS3** – Styles the application and makes it responsive.
- **JavaScript** – Handles task management and user interactions.

todo-list-app/

## 🚀 How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter a task and add it to your list.
5. Mark tasks as completed or delete them as needed.
